AuthForge Documentation

AuthForge provides simple, secure API authentication infrastructure for developers. Add API key authentication to your applications in minutes.

Get Started Free → Try the Playground

Quick Start

Get up and running in 3 steps:

1. Create an account

Sign up at authforge.dev/signup. No credit card required.

2. Generate an API key

From your dashboard, click Generate API Key. Copy the key immediately — it's shown only once.

3. Make your first request

curl -X GET \
  https://YOUR-SITE.netlify.app/api/user \
  -H "Authorization: Bearer af_live_YOUR_KEY"

Authentication

All API requests require a valid API key passed as a Bearer token in the Authorization header.

Authorization: Bearer af_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

API keys are prefixed with af_live_ for production or af_test_ for test environments. Never expose your API key in client-side code.

⚠ Security: API keys grant full access to your account data. Store them as environment variables, never in source code.

API Endpoints

Base URL: https://YOUR-SITE.netlify.app/api

GET /user

Returns the authenticated user's profile information.

POST /validate

Validate an API key without returning user data. Useful for middleware.

POST /api/validate

Request Body

{
  "apiKey": "af_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}

Response 200

{
  "valid": true,
  "userId": "usr_abc123",
  "keyId": "key_xyz789"
}

Error Codes

AuthForge uses standard HTTP status codes. Error responses include a code and message field.

StatusCodeDescription
401UNAUTHORIZEDMissing or invalid API key
403FORBIDDENKey exists but account is disabled
429RATE_LIMITEDToo many requests
500INTERNAL_ERRORServer-side error
 
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid API key provided",
    "docs": "https://authforge.dev/docs#errors"
  }
}

API Key Management

API keys can be managed from your dashboard or programmatically.

  • Keys are shown only once at creation — copy them immediately
  • Keys are stored as SHA-256 hashes — we cannot recover a lost key
  • You can generate multiple keys per account
  • Keys can be named, disabled, and deleted at any time

Rate Limits

Free tier: 1,000 requests/day per API key. Rate limit headers are included in every response:

X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 857
X-RateLimit-Reset: 1736956800

Security

AuthForge is designed with security-first principles:

  • API keys are hashed with SHA-256 before storage
  • HTTPS enforced on all endpoints
  • Keys are shown only once at generation
  • All requests are logged with timestamps
  • Firebase Security Rules restrict data access

SDKs & Code Examples

Node.js

const response = await fetch('https://YOUR-SITE.netlify.app/api/user', {
  headers: { 'Authorization': `Bearer ${process.env.AUTHFORGE_API_KEY}` }
});
const user = await response.json();

Python

import os, requests

response = requests.get(
  'https://YOUR-SITE.netlify.app/api/user',
  headers={'Authorization': f'Bearer {os.environ["AUTHFORGE_API_KEY"]}'}
)
user = response.json()

PHP

$ch = curl_init('https://YOUR-SITE.netlify.app/api/user');
curl_setopt($ch, CURLOPT_HTTPHEADER, [
  'Authorization: Bearer ' . $_ENV['AUTHFORGE_API_KEY']
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$user = json_decode(curl_exec($ch));
